# Стартовый набор: сценарии Vanessa с агентом

Набор для сценарных тестов форм 1С агентом через MCP Vanessa Automation. Распакуйте его
в новый репозиторий первым коммитом.

## Что где

| Путь | Что это |
| --- | --- |
| `.agents/skills/testing-with-vanessa/SKILL.md` | скилл агента: порядок работы со сценариями, рабочие шаги Gherkin, грабли и раздел «Под своё окружение» — пример подключения MCP на Windows |
| `features/НовыйТовар.feature` | рабочий сценарий-образец: создание товара в демо-БСП с проверкой списка |
| `tools/vanessa-automation-single.epf` | обработка Vanessa Automation 1.2.043.45 |
| `tools/client_mcp.cfe` | расширение `client_mcp` 0.6.6 (onec-client-mcp-devkit) — MCP-сервер менеджера тестирования |
| `start-mcp.ps1` | запуск клиента тестирования на рабочей базе и менеджера с MCP (значения машины — в скилле, раздел «Под своё окружение») |
| `va.ps1` | пакетный прогон сценария: отчеты в `reports/run-<дата-время>`, сам проверяет `status.txt` и JUnit |

Источники: релизы GitHub `Pr-Mex/vanessa-automation` и `1c-neurofish/onec-client-mcp-devkit`.

## Порядок

1. Положите скилл в каталог скиллов своего агента (`.agents/skills/`, `.claude/skills/`
   или `.cursor/skills/`).
2. Пройдите раздел скилла «Под своё окружение»: база-менеджер с `client_mcp`, строка
   `conf.cfg`, профиль клиента тестирования, запуск клиента и менеджера с MCP, запись
   MCP для своего харнесса, пакетный прогон. Команды там — наш пример для Windows
   и файловой базы; адаптируйте их и закоммитьте скилл.
3. В образце замените `<профиль>` на имя профиля из своего `VAParams-mcp.json`.
4. Запустите агента после менеджера и попросите прогнать образец через MCP, затем
   пакетно: `status.txt` — `0`.

Каталоги логов и отчётов, снимки падений Vanessa (`png/` рядом с feature) в git не
кладите.
